## 一、典型使用流程
> 补充：开发者已毕业可能不会继续维护此项目，本项目初衷是在学校内完成截图任务收集（例如团支书等其他思想学习任务）。如运行不了请遵守文件目录。
### 0. 使用前提（重要设置）
在使用机器人提交截图前，**请务必将手机QQ的截图发送方式修改为“半屏发送”**。这样可以在输入命令的同时方便地附上截图，确保命令和图片在同一条消息中发送给机器人，否则可能导致提交失败。

### 1. 班级初始化（班长/管理员操作）
1.  **获取信息**：向超级管理员或上一任管理员询问本班的**数据库名称**和**管理员密码**。
2.  **绑定群**：在班级群内使用 `绑定群` 命令，格式为：`@机器人 绑定群 [班级名] [数据库名称] [管理员密码]`。
3.  **立即撤回**：绑定成功后，**立即长按撤回**您发出的绑定命令消息，防止密码泄露。
4.  **通知绑定**：通知全班同学使用 `绑定用户` 命令绑定自己的学号（详见下方）。

### 2. 成员绑定（每个用户只需做一次）
1.  **绑定信息**：班级所有成员在群内使用 `绑定用户` 命令，格式为：`@机器人 绑定用户 [学号] [密码]`。
    - 初始密码通常就是**学号本身**。
    - 此操作仅需在初次使用时执行一次，绑定成功后永久有效，无需重复绑定。

### 3. 任务创建与提交（日常使用）
1.  **创建任务**：管理员或超级管理员使用 `新建任务` 命令创建院级或班级任务。机器人会返回一个**任务ID**。
2.  **通知任务ID**：管理员将任务内容和**任务ID**通知全班同学。
3.  **提交截图**：普通用户使用 `sub`（提交学院任务）或 `submit`（提交班级任务）命令，并附上截图。格式为：`@机器人 sub [任务ID] [图片]`。
4.  **监控进度**：管理员或超级管理员使用 `统计任务` 命令，查看已提交和未提交名单，进行督促。

### 4. 任务收尾（打包归档）
1.  **手动打包**：任务收集完毕后，管理员或超级管理员可使用 `打包任务` 命令，将所有人提交的截图自动添加水印（包含提交时间、姓名、班级、学号）并打包成一个压缩文件。
2.  **自动打包**：对于性能较好的服务器，系统会**自动监测班级任务完成度**。一旦检测到全班所有成员均已提交，无需人工干预，机器人会立刻触发水印添加和打包流程，实现全自动归档。

## 权限体系与术语

| 等级 | 身份 | 权限范围 | 术语代称 |
| :--- | :--- | :--- | :--- |
| **1** | **超级管理员（超管）** | 管理学院所有事务，可操作任意群组数据。 | 超管 |
| **2** | **管理员** | 管理其所在班级群的任务、成员信息。使用“绑定管理员”命令获得**永久**身份。 | 管理员 |
| **3** | **普通用户** | 绑定个人信息、提交截图。 | 用户 |

- **权限覆盖**：
    - 超管 > 管理员 > 用户。高级别可查看低级别信息，但各自命令独立。
    - **当一个用户同时拥有超管和管理员权限时，超管权限会完全覆盖管理员权限**，即该用户可执行超管和管理员的所有命令，但在系统中其操作行为会以超管身份被记录和校验。
- **使用范围**：
    - **群聊命令**：在班级群 @机器人 使用。
    - **私聊命令**：在与机器人的私聊窗口使用。
    - **注意**：涉及密码修改的命令（如设置群密码、设置用户密码）**仅限私聊**。

> QID 即 QQ为每个用户以及群聊分配的内部ID，通常可以在机器人后台日志中查看。

## 关键概念详解

### 1. 任务精度（图像查重）
- **比对对象**：当前任务下**同一班级群内**所有已提交者之间的截图进行比对。跨班级不会互相检测。
- **触发条件**：新提交图片与任意已提交图片的相似度 **≥ 设定精度** 且 **非提交者本人** 时，判定为盗用，拒绝提交。
- **取值**：有效值为小数（如 `0.99`、`0.8`）或 `0`、`False`、`false`。后者表示不检测。

> 建议设置为0.98意为98%。

### 2. 班级与数据库名称
- `绑定群` 命令中的 `[班级名]` 为显示用名称，`[数据库名称]` 为后台班级文件名（不含扩展名）。通常两者相同，仅当后台文件名与班级名不一致时才需区分。**请务必向管理员确认准确的数据库名称。**

### 3. 密码体系
- **班级管理员密码**：用于绑定群、绑定管理员、设置群密码。由绑群时设定，遗忘需由超管通过私聊“设置群密码”重置。
- **学生个人密码**：用于绑定用户。初始为学号，遗忘可由管理员或超管通过私聊“设置用户密码”重置。

### 4. 任务ID
- 创建任务后，机器人会立即返回一个数字任务ID。该ID用于提交、统计、修改精度、删除、打包等后续操作。用户可通过“查看任务”命令获取当前所有任务及其ID。
- 如果当前只有唯一一个任务，在“删除任务”“更改匹配度”“打包任务”等命令中可以省略任务ID，系统自动指向该任务。

### 5. 打包与水印
- 当任务收集完毕后，管理员或超管可执行“打包任务”命令。机器人会自动为每张截图添加文字水印，内容包含：**提交时间、学生姓名、班级、学号**。然后所有图片压缩为一个zip文件，方便存档或上报。
- 若服务器性能良好，系统会实时监测班级提交进度，一旦全班提交完毕，**无需手动操作**，机器人立即自动完成水印添加和打包，实现零延迟归档。

### 6. 数据删除说明
- 执行“删除群”“删除本群”后，该群的用户绑定信息及所有提交的截图将被**彻底清空**，请谨慎操作。

### 7. 管理员变更
- 若班长换人，新班长可直接使用“绑定管理员”命令输入班级密码即可获得管理员权限。若需更换班级密码，可联系超管在私聊执行“设置群密码”。

## 常见问题与排查

1.  **命令无反应**：检查是否列表中选择机器人、参数间是否有空格、命令是否在正确的范围（群聊/私聊）。
2.  **绑定失败/学号错误**：确认后台数据问题后联系物联网2407王甫星或田伟修正。若联系人毕业，联系学生会。
3.  **忘记管理员密码**：由超管通过私聊 `设置群密码` 重置。
4.  **统计任务提示“没有传入QID”**：管理员也必须提供本群QID，可先使用 `本群信息` 命令获取，然后执行 `统计任务 [任务ID] [QID]`。
5.  **删除本群误操作**：删除后数据不可恢复，请谨慎使用。
6.  **提交截图失败（无图片）**：请检查是否已改为“半屏发送”模式，确保图片与命令一同发送。

## 数据库准备（管理员/超管后台操作）

管理员绑定班级前，需要将班级成员数据预先导入系统，否则无法完成绑定及后续提交。

1.  在机器人源代码的 `tools` 文件夹下找到 **“新建班级文件夹”**，其中包含 `excel` 文件夹、`json` 文件夹以及 `main.py` 脚本。  
    `main.py` 的作用是读取 Excel 格式的班级名单，并将其转换为机器人可直接读取的 JSON 数据库文件。

2.  将各班级的学生名单 Excel 文件放入 `excel` 文件夹。  
    **文件命名规则**：`班级名.xlsx`（例如 `数媒2501.xlsx`）。  
    **表格格式要求**：
    - 第一行作为标题行，A 列为“姓名”，B 列为“学号”。
    - 从第二行开始填入学生数据，每行一名学生，例如：

    | 姓名 | 学号 |
    |---|---|
    | name1 | 143572503000281 |
    | name2 | 143572503000282 |
    | ... | ... |

3.  运行 `main.py`，程序会自动扫描 `excel` 文件夹下的所有 `.xlsx` 文件，并在 `json` 文件夹中对应生成 `班级名.json` 文件。

4.  将生成的 JSON 文件全部复制或移动到机器人源代码的 **`class`** 文件夹中。  
    此时，各班级的数据库即准备就绪。

5.  完成上述步骤后，班级管理员方可执行 **“绑定群”** 命令，随后班级成员即可通过 **“绑定用户”** 命令绑定个人学号。当班级群成功绑定且成员完成绑定后，即可正常创建和提交任务。
